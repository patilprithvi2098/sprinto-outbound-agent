Every phase ends with: playwright-qa passes on the screens it touched, Impeccable detector clean on those pages, result matches DESIGN.md, and a git commit (rollback = `git reset --hard` to the previous phase's commit). All phases run on localhost only (the app holds Claude, Hunter and Gmail credentials). Cut line: no new features after Phase 4 starts. Freeze: copy and names frozen once Phase 4 is done; only bug fixes after that. Deadline not yet given; time boxes are estimates (about 14.5 h total).
